Quick Web Installation Guide
1
Connect your ESP32 CYD board to your computer via USB using Google Chrome or Microsoft Edge.
2
Click Install AMK Launcher below and choose your board's serial port (e.g. COM4).
3
Format MicroSD as FAT32. Put .bin files inside /apps/, and place supporting folders (like Weather Station icons/ and flags/) directly in the root directory.
Step 1: Flash AMK Multi-Boot Launcher

Flashes KeyBoot interceptor bootloader, 4MB custom partition table (1.34 MB SPIFFS + 1.92 MB App slot), and AMK Launcher UI.

⚠️
Emergency Return: If any loaded application freezes or you want to return to the launcher, simply hold down the BOOT button (GPIO 0) while powering on or resetting the device!
Step 2: MicroSD Card App Setup Guide

Drop any compiled ESP32 Arduino / ESP-IDF .bin into your MicroSD card. No code changes required!

@ 
/ (MicroSD Card Root - FAT32)
├── apps/
│   ├── FlightRadar.bin        <- Live Aircraft Radar Tracker
│   ├── FlipClock.bin          <- Retro Split-Flap Clock

├── BMP32X32/                  <- Compact Weather Icons (Root)
├── BMP64x64/                  <- High-Res Weather Icons (Root)
├── flags/                     <- Country Flags (Root)
└── Logo/                      <- AMK Logos & Splash Assets (Root)
⚠️ Important SD Card File Placement:
  • Application Binaries: All application .bin files must be placed inside the /apps/ folder (e.g. /apps/FlightRadar.bin, /apps/WeatherStation2.8.bin).
  • Weather Station Supporting Assets: Folders like /BMP32X32/, /BMP64x64/, and /flags/ MUST be placed directly in the ROOT of the SD card, NOT inside /apps/!
